s výhradně syntetickými ukázkovými údaji. E-maily používají doménu example.com,
telefonní čísla jsou záměrně neplatná a žádný záznam se neukládá do backendu.
Náhled spustíte příkazem `node docs/releases/2026-09-14/preview.mjs`.
Původní výřezy přihlášené aplikace nejsou součástí publikované dokumentace.

PDF lze znovu vytvořit pomocí `build-guides.py` s ReportLab a Pillow.
Generátor na macOS používá systémové Arial fonty. Návody popisují uživatelské
chování ověřené proti technické dokumentaci
[propojení smluv](../../development/contract-bid-navigation.md) a
[příjemců poptávky](../../architecture/pipeline-recipient-selection.md).
