# Tender Flow v1.9.25

Patch sjednocuje vzhled veřejných obrazovek s aktuální landing page a doplňuje skin TF basic ve světlé i tmavé variantě.

## Vzhled a ovládání

- Přihlášení, registrace, obrazovka po odhlášení a obnova hesla používají společnou paletu landing page.
- Nový skin TF basic lze vybrat v nastavení vzhledu aplikace; podporuje světlý i tmavý režim.
- Součástí vydání jsou aktuální úpravy landing page, včetně postupu výstavby v úvodní sekci.

## Verze a desktop

- Web i desktop používají shodnou verzi 1.9.25. Verze v main a release jsou sjednoceny, aby lokální sestavení z main nehlásilo starší 1.9.22.
- Vydání navazuje na 1.9.24 a zachovává předchozí opravy MCP a desktopového přihlášení.
- Instalační soubory pro macOS (Apple Silicon) a Windows (x64) se sestavují lokálně. GitHub Actions slouží pouze k ověření a nevkládá soubory do GitHub Release.
