# Tender Flow v1.9.39-beta.2

Beta pro Windows x64 s opravou notifikací a úpravami rozpočtů z předchozí bety.

- Kliknutí na notifikaci ji ihned skryje bez přesměrování a načítání jiné obrazovky.
- Při neúspěšném skrytí se seznam obnoví a zobrazí chybu.
- Pravidelné půlminutové kontroly nahrazuje aktualizace přes živé spojení;
  při jeho výpadku se seznam kontroluje po pěti minutách.
- Desktopová upozornění se zobrazují pouze pro varování a chyby.
- Zachovány jsou úpravy položek rozpočtu přímo v tabulce a přiřazování celých
  položek do VŘ z verze 1.9.39-beta.1.

Jde o předběžné vydání. Pravidla čištění notifikací v databázi se nemění.
Windows instalátor nemá Authenticode podpis. Skutečná instalace a aktualizace
na Windows nebyla na macOS sestavovacím počítači ověřena.
