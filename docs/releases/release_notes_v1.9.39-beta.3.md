# Tender Flow v1.9.39-beta.3

Beta pro Windows x64 s kartou objednatele stavby.

- V **Dokumenty → Objednatel** lze uložit firmu, IČO, adresu, kontaktní osobu
  a interní poznámku. Karta je volitelná a dostupná také z přehledu stavby.
- Identita objednatele zůstává oddělená od finanční evidence smluv. Jméno se
  do smlouvy přenese až po potvrzení.
- Uživatelská i firemní záloha zahrnuje kartu objednatele. Obnova doplní
  chybějící kartu, ale nepřepíše aktuální údaje; funguje i pro archivované stavby.
- Při klonování nabídky do realizace se přenese také karta objednatele.
- Opraveno smazání posledního editora karty u archivované stavby.
- Zachovány jsou opravy notifikací a úpravy rozpočtů z předchozích bet.

Jde o předběžné vydání. Windows instalátor nemá Authenticode podpis.
Skutečná instalace a aktualizace na Windows nebyla na macOS sestavovacím
počítači ověřena.
