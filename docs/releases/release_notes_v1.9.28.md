# Tender Flow v1.9.28

Opravné vydání odstraňuje pravidelné přerušování práce při kontrole předplatného.

- Kontrola předplatného na pozadí už kvůli běžné prodlevě serveru krátce nezobrazuje obrazovku „Kontaktovat podporu“ a nezavírá rozepsaný formulář.
- Při úspěšném ověření zůstává zachovaný rozepsaný text i fokus. Skutečné vypršení předplatného a odebrání přístupu se nadále kontrolují.
- Windows nadále získává aktualizace z obou veřejných repozitářů. Instalace nové verze vyžaduje restart aplikace; macOS zůstává u ruční aktualizace.

Windows x64 a macOS Apple Silicon instalátory vznikají lokálně. Vydání nevyžaduje změnu databáze ani nové závislosti.
