# Tender Flow v1.9.39-beta.4

Beta pro Windows x64 s úspornější aktualizací projektů.

- Změny nabídek obnovují jen nabídky dotčených kategorií. Smlouvy, finance
  a další části projektu se při každém takovém oznámení znovu nestahují.
- Více změn přijatých krátce po sobě se sloučí do jedné obnovy.
- Pravidelné obnovování projektu se pozastaví ve skrytém okně a bez připojení.
  Po návratu nebo obnovení spojení aplikace zkontroluje aktuální data.
- Zůstává minutová záložní obnova viditelného projektu pro zachycení smazání,
  zmeškaných změn a odebrání přístupu.
- Databázové vyhodnocování přístupu k nabídkám je optimalizováno při zachování
  oprávnění, oddělení firem a kontrol předplatného.
- Zachována je karta objednatele a opravy z předchozích bet.

Jde o předběžné vydání. Windows instalátor nemá Authenticode podpis.
Skutečná instalace a aktualizace na Windows nebyla na macOS sestavovacím
počítači ověřena.
