# Tender Flow v1.9.36

## Sjednocení postranního menu

- Vybraná stavba ve vzhledu Industrial přebírá pozadí sidebaru místo bílého bloku. Úprava platí pro světlý i tmavý režim.
- Rozbalovací položky Smlouvy a Nastavení stavby mají stejné rozměry a velikost ikon jako ostatní položky stavebního menu.
- Zvýraznění položek Přehledů a Nástrojů při najetí myší pokrývá celou šířku menu. Podnabídky zachovávají odsazení obsahu.

## Distribuce

Patch nemění závislosti, oprávnění ani databázové schéma. Instalační soubory pro Windows x64 a macOS Apple Silicon se sestavují lokálně.
