# Tender Flow v1.9.35

## Oprava startovní obrazovky

- Běžný start aplikace a přihlášení bez přímého cíle otevřou **Stavby → Všechny** místo TODO.
- Výchozí pohled Všechny se otevře i po předchozím použití Archivu.
- Přímé odkazy na stavby, úkoly a další sekce zůstávají funkční. Návrat z detailu zachovává filtr zvolený během práce.

Verze obsahuje také změny z 1.9.34, která byla stažena z veřejné distribuce. Podrobnosti jsou v [poznámkách k 1.9.34](release_notes_v1.9.34.md).

## Distribuce

Instalátory Windows x64 a macOS Apple Silicon jsou sestavené lokálně. Windows instalátor není podepsaný; macOS aplikace je podepsaná ad-hoc a není notarizovaná. Verze nezavádí nové migrace ani změny závislostí oproti 1.9.34.
